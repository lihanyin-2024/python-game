💎 消消乐大作战
这是一个使用 Python 和 Pygame 开发的经典三消益智游戏。玩家需要在有限的步数内，通过交换相邻的宝石来达成收集目标。

📂 项目结构说明
为了保证游戏正常运行，请严格遵守以下文件结构：
消消乐大作战/
├── game.py          # 游戏主程序
└── image/               # 游戏素材文件夹
    ├── background.png   # 游戏背景图
    ├── gameboard.png    # 棋盘区域背景
    ├── scorebar.png     # 分数与目标栏
    ├── gameover.png     # 游戏结束画面
    ├── gem1.png         # 宝石素材 1
    ├── gem2.png         # 宝石素材 2
    ...
    └── gem7.png         # 宝石素材 7 (如缺失可能导致报错)
🎮 玩法规则
胜利条件：在规定的 12 步 内，收集到左上角和左下角显示的两种目标宝石各 9 个。
消除规则：点击选中一个宝石，再点击其上下左右相邻的宝石进行交换。如果交换后能连成 3 个或以上同色宝石，则消除成功。
连锁反应：消除后上方宝石会下落填补空缺，并可能触发新的消除。
洗牌机制：如果当前局面无法进行任何有效消除，系统会自动重新排列宝石（洗牌）。
